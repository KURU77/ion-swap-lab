# イオン置換ラボ

神経細胞で働く Na⁺・K⁺・Ca²⁺ を別の金属イオンに置き換えたとき、平衡電位・静止膜電位・相対透過性がどう変わるかを試算する GUI シミュレーターです。Google Colab で作った Python 版のシミュレーションと同じ式を、ブラウザ上で動くように移したものです。

依存ライブラリはありません。`index.html` ひとつで動き、パソコンでもスマホでも使えます。

## 使い方

- **パソコン**：`index.html` をダブルクリックしてブラウザで開くだけで動きます。
- **スマホ（iPhone）**：公開した URL を Safari で開き、共有ボタン →「ホーム画面に追加」を選ぶと、アプリとして使えます（オフラインでも動きます）。

## 画面

| タブ | できること |
|---|---|
| 1ケース | Na役・K役・Ca役 に入れるイオン、濃度の決め方、透過性 P の決め方を選ぶと、静止膜電位・平衡電位・細胞内外の物理量・判定がすぐに表示される |
| 組み合わせ | 2 つの持ち場の全組み合わせをヒートマップで表示する（静止膜電位・体積分率・イオン強度・浸透圧差）。マスをタップすると詳細が出て、「1ケース」で開ける。CSV 保存もできる |
| 透過性 P | チャネルごとの較正パラメータ、実測値の再現、全イオンの予測 P 比と K_d |
| イオン表 | 候補 27 イオンの性質、理論最大濃度、活量係数のグラフ |
| 設定 | 温度、生体の濃度・透過性、しきい値、P モデルのパラメータ、較正データ（JSON） |
| 説明 | 考え方と式のまとめ |

設定はブラウザの中（localStorage）だけに保存され、外部には送信しません。

## モデルの概要

- **平衡電位**：Nernst 式（活量で計算）
- **静止膜電位**：価数の違いに対応した GHK 電流式で、正味の電流が 0 になる電位を二分法で求める
- **活量**：Davies 式（温度に合わせて水の比誘電率を補正）
- **物理的に成り立つか**：電気的中性（不透過陰イオンで自動調整）、水和球の体積分率、浸透圧、Bjerrum 比によるイオン対
- **相対透過性 P**：脱水和コスト＋結合部位とのクーロン引力（Eisenman）、立体的なふるい（Hille）、Eyring 型の障壁、飽和による詰まり。Hille（1972, 1973）の実測値と L 型 Ca チャネルの概略値に差分進化法で当てはめる

## 限界

- 静止状態だけを扱っています（活動電位は扱っていません）。
- 水和イオンを硬い球とみなす近似です。不透過陰イオンは 1 種類にまとめています。
- 浸透圧差による細胞の体積変化や、Na/K ポンプでの輸送は計算していません。
- P モデルは結合部位が 1 つという近似です。Ca チャネルの較正値は概略値です。

## ファイル

- `index.html` … アプリ本体（計算モデルは `// <model>` 〜 `// </model>` の間）
- `manifest.webmanifest`, `sw.js` … ホーム画面への追加とオフライン動作
- `icons/` … アイコン（`node icons.mjs` で再生成）
