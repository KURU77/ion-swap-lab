このアプリでできること

神経細胞で働く Na⁺・K⁺・Ca²⁺ を別の金属イオンに置き換えたとき、平衡電位と静止膜電位がどう変わるか、その状態が物理的に成り立つかを試算します。Google Colab で作ったシミュレーションと同じ式を使っています。

持ち場（Na役・K役・Ca役）

「Na役」は Na⁺ という名前ではなく、生体で Na⁺ が担っている持ち場（濃度の配置と、通るチャネル）のことです。

  • Na役：外に多く内に少ない。速く開くチャネルを通って流れ込み、脱分極させる（活動電位の立ち上がり）。
  • K役：内に多く外に少ない。流れ出して膜を元に戻す。静止膜電位を決める。
  • Ca役：内が極めて少ない。流れ込むこと自体が信号になる。静止時のチャネルはほぼ閉じている。

濃度の決め方

  • 同モル：元のイオンと同じ mM。
  • 同電荷：z × 濃度 を元と同じにする。
  • 同体積：水和したイオンが占める体積を元と同じにする。

3つとも細胞内外の濃度比は変えません。そのため理想溶液の Nernst 電位は価数だけで決まります。濃度の絶対値は、活量・電気的中性・浸透圧・GHK 静止膜電位を通じて効いてきます。

使っている式

E = (RT / zF) ln(aout / ain)、 a = γ c
Ii(V) = Pi zi F u (ain − aout e−u) / (1 − e−u)、 u = ziFV/RT、 Σ Ii(Vrest) = 0
log₁₀ γ = −A z² (√I / (1 + √I) − 0.3 I)（Davies 式）
Gwell = f |ΔGhyd| − K z q / (r + rsite)、 P0 ∝ (1 − r/rpore)² exp(−α Gwell/RT)、 P = P0 / (1 + c/Kd)

透過性 P の決め方

  • 継承：受容体も完全に置き換える。P は元のイオンと同じ。
  • 既存チャネル：元のチャネルのまま、新しいイオンを通す（実測値で較正）。
  • 相似チャネル：チャネルの大きさを新しいイオンに合わせて作り直す。イオン固有の差（脱水和のしにくさ・価数）だけが残る。

判定

  • 体積超過（φ が上限を超える）・中性不可（陰イオンが余る）→ 存在できない
  • Davies範囲外（I が上限を超える）・浸透圧差・イオン対（Bjerrum 比 > 1）→ 注意
  • 軟イオン・価数外挿 → 透過性の予測が不確か

限界

  • 静止状態だけを扱っています。活動電位の形は扱っていません（次の段階で HH モデルを追加する予定）。
  • 水和したイオンを硬い球とみなす近似です。不透過陰イオンは 1 種類にまとめています。
  • 浸透圧差による細胞の体積変化や、Na/K ポンプでの輸送は計算していません。
  • P モデルは結合部位が 1 つという近似です。Caチャネルの較正値は概略値です。
